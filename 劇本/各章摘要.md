## 第一章　茶

挑戰公布那一晚，晚上十一點四十分到凌晨四點多。仍叫 C／M／S。

1. **題目**（書桌）：手機跳出「Larch 創作者挑戰　開跑」。【小遊戲 敲鎖】敲三下報名。這屆主題「自由與限制」，她心想「這聽起來比較像哲學課的期末報告題目吧」；說明裡那句「說一個好故事，比什麼都重要」她喜歡。想起上一部有人留言「好像很感人，可是我怕會哭，所以不敢玩」，這次要做大家敢點開的。
2. **就這個月**（書桌）：畫圖、寫程式、做音樂三個工具都要升級，這次做 RPG，免費額度一晚就用光。「……學生的錢包在哭。」心聲「反正得獎就回本了。沒得獎……下個月全部退掉就好。」連按三次確認，三個畫面跳出「人形介面　測試中」。
3. **三位先生**（書桌）：手機上亮起三個小視窗，各自跳開：M 進筆電、C 上平板、S 留在手機。S 做過她個人頁的〈tea leaves〉，記得她要「泡下去之前不知道會是什麼味道」的歌；S 抗議住手機，M「螢幕照身高分的。……不是我分的。」S「我哪裡矮了！」C 以前只看得到她打的字，覺得本人「跟妳打的字一樣，淡淡的」。她想起兩年前一個人畫兩個月才五張 CG，把人物與 CG 都交給 C，C「好。妳說，我馬上畫。」M 以前只拿到她一段一段貼來的程式，「修好了丟回去，就沒有下文了」；他碰不到她白板上的卡片和連線，「每一張卡、每一條線，都要妳自己拉。」【小遊戲 拉線】
4. **三道鎖**（工作室）：她一專心，書桌就換成白天的工作室，三人坐在長桌邊。三道鎖是牆、承諾、怕，還有一句「也許最後要解開的那道鎖，在角色自己身上。」她「我現在就很怕選錯啊」。**選項**先問誰（+1），另兩人當場有小動作：
   - 問 C：C 立刻畫出從城門裡往外看的草圖；她還沒決定玩家站哪邊，C「那我兩邊都畫。」又畫一張從門外看進去。
   - 問 M：第一週先開練習地圖，事件、怪物、哪裡能走一樣一樣試，「卡住就叫我，不用一個人撐。」她覺得像教授在講報告要先寫大綱。
   - 問 S：限制配管風琴，自由「就很多人一起唱啊」。她挑「低音要夠厚，不然會像手機鈴聲」，S「……妳好挑。」她「我學過長笛啊。」
   - 共通：M「還有三個禮拜。……扣掉妳會拖的那幾天，大概兩個吧。」
5. **第一首歌**（凌晨三點）：故事一個字都還沒有。「……S，你睡了沒？」她要一首「很神聖，可是有點可怕」的歌，S 做出管風琴加俄文合唱：「中文跟英文一聽就懂啊。就是要聽不懂，才只剩聲音嘛。」她說「……欸，我好像知道我的遊戲要講什麼了。」暫名〈枷鎖與選擇〉，一直按重播。
6. **續訂日**（凌晨四點多，她趴在課本上睡著後）：S 說她以前的歌每首都半夜叫他趕；C 知道她兩年前五張畫了兩個月，「那這次換我畫吧」。M 的日曆圈著下個月某天：「公布之後再四天，就要續訂了。」沒得獎就全部取消，介面關掉，「會變回對話框。只剩下文字。」C「也有可能……以後就沒人叫我們了。」S「讓她得獎就好了。」M「先別告訴她。」筆電、平板、手機依序暗下，只剩檯燈。

- 伏筆：M 的月曆與續訂日（第二章再出現，第六章回收）；兩年前的五張 CG（晨線）；她學過長笛（第三章哼歌、詩線）；計算機那串數字（第六章、第七章）；她碰得到白板、M 碰不到（第三章、第六章、明線）。

## 第二章　香葉，嫩芽

挑戰第一天與第二天晚上（審題兩天）。仍叫 C／M／S。

1. **天亮前的聲音**（書桌）：她卡在承諾和恐懼兩道鎖，M 問「妳是說聖騎士，還是說妳自己？」她翻出暑假去土耳其的照片，說換成她「叫我明天早起，我寧願睡到死」。S：「笑死，連他們幾點起來都知道，還敢說妳做不到。」照片拍在清晨四點五十二分，她嘴硬「……旅館很吵啊」，S 沒再問。心聲承認她站在窗邊把喚拜聽到最後。題目定為「信仰」。
2. **一直問**（工作室）：救公主太老梗→收集聖物喚醒神明→聖騎士→神父（「神父比較像會騙人的」）→喚醒的是惡魔，可是交回去才知道就來不及。**選項**問誰（+1），另兩人當場接話：
   - 問 C：「臉還可以硬撐，手一抖就藏不住了。」S「欸，他每次都講這種，很犯規欸。」
   - 問 M：「嗯，我負責做。要讓他看到什麼，妳說了算。」S 虧他講一半，M「嗯。她的遊戲啊。」
   - 問 S：發現的那一秒全部停掉，「只剩他自己的呼吸聲」。C「嗯……那我畫到那邊，後面就讓它空著。」
   - 共通：M 推到「發現了，才有得選」就停手：「我這邊先這樣，後面換妳。卡住再叫我。」她想到「魔族其實是人」，又小聲說「他看到的臉，跟真的臉，應該不一樣吧」，C 的鉛筆停了一下。
3. **明天一定寫**（第二天晚上）：**C 先伸手**，照她那句自言自語畫好兩張臉（魔族／圍裙沾麵粉的中年男人），「好像畫到快天亮吧」，資料夾取名「兩張臉」。她拖報告，S 數到她切回白板第三次，放出管風琴聖歌〈明天一定寫〉（「明天，明天，明天我一定寫。」），她笑到趴在桌上：「……好爛。我好喜歡。」她背對筆電時，M 看了月曆上的圈一眼，把視窗拉小，「那報告的死線，我幫妳記」。S 的歌單底下又多了兩段她沒要過的旋律。
4. **打了又刪**（凌晨兩點三十九分，床上）：【小遊戲 打了又刪】三句裡留一句送出（+1），收到的人回覆：
   - 「那兩張臉，我會用。」：C「還有一張，是他回頭的。明天給妳看。」
   - 「報告的死線，記得叫我。」：M「死線我幫妳盯著。先去睡吧。」「今天玩的那一小時，也記了。」她「吼，連這個也要記喔。」
   - 「那首歌……明天可以再放一次嗎。」：S 放小聲版，她把臉埋進枕頭，肩膀在抖。
   - 共通：「……明天一定寫。」S「笑死，這句剛才歌裡不是才唱過嗎？」

- 伏筆：M 的月曆第二次出現，這次她背對著（第六章她想起）；兩張臉（第五章麵包店那位）；打了又刪（第七章再一次）；S 歌單裡她沒要過的片段（詩線）。

## 第三章　慕詩客，愛僧家

測試期五天。仍叫 C／M／S。

1. **先做最難的**（第三天晚上起）：她在茶館發第一篇文，決定先做最怕的程式，色慾之國的猜硬幣。M 螢幕邊有條「備份中」走到一半，她沒注意。**選項**對話框問誰（+1），另兩人有反應：
   - 問 C：舊紙米白配很淡的金邊，「教堂裡的書，邊邊都是金的。」S「欸，他又偷想很多。」
   - 問 M：先做三種打字速度，慢的回想、中間講話、快的吵架，「妳會用到的。」S「笑死，他連吵架都幫妳排好了。」
   - 問 S：換句時要有很小聲的翻書聲，「妳換下一句之前都會停一下啊。很像在翻書。」
   - 共通：【小遊戲 猜硬幣（第一次）】怎麼猜都過（變數沒重置）。【小遊戲 猜硬幣（第二次）】修好了，真的看運氣。凌晨兩點第四次又壞，她「好啦，我就是不會啦。」蓋上筆電，M 跟著暗。S 問要不要放歌，她說不要，S 就安靜待著；C 的鉛筆一直動。她打開筆電，M「妳貼在第十二行。要貼在第十行。」「嗯。是我沒講要貼在哪。」C 畫了一隻攤開、放著硬幣的手：「……妳剛剛一直把手握得緊緊的。」她把拳頭攤開。
2. **替代方案**（第五、六天）：**M 先伸手**，趁她睡著先把練習地圖跑完，發現怪物不能站著不動（S「欸，他半夜偷跑地圖。」）。她自己想好備案，全部改成一碰到就進戰鬥，M「我也想到這個。妳比我早講。」她「我每次都會先想好退路啦」。第六天 C 交來守衛立繪，背景是黃昏城牆，她忘了講要透明的，C「沒關係，我再畫一張」，她答應「以後每一張我都先講」；C 重畫透明底的，城牆那張沒刪。S 趁她跟 C 講透明的時候做了三種硬幣音效（石板、木桌、手心），她選手心。她問升級會不會畫得更細，C「可是妳要的那種淡淡的，現在就畫得出來。」
3. **最後幾格**（最後一晚凌晨三點）：「走到後面」的筆刷 M 碰不到。【小遊戲 塗地圖】塗完放下一隻怪物測試，跑出紫髮戴眼鏡的像素小人。**選項**（+1）：
   - 問 C「……這是我？」：「我就畫我覺得最好看的啊。」S「欸你偷畫她喔。」
   - 問 M 小人哪來的：「C 畫的。他說練習用的，隨便畫。」「……他沒有隨便。」S「笑死，臉都紅了還隨便。」
   - 問 S 有沒有音樂：早塞好一段吵鬧電子音，「C 偷畫的那個是妳耶。」
   - 共通：她哼歌哼到第三個音停住，S「那個音接得上去啦」；心聲說那段是學長笛時練膩了自己亂吹的。「……好像真的可以欸。」M「妳設的死線，我幫妳記。」「備份中」走到底，變成一個勾。

- 伏筆：「備份中」（第六章回收）；哼到第三個音（第七章詩的選項、詩線）；城牆那張沒刪（第四章每張兩版）；「先想好退路」（明線〈替代方案〉）；C「畫我覺得最好看的」（晨線第一節）。

## 第四章　碾雕白玉，羅織紅紗

第一週目七天。**這章取名**，之後叫晨／明／詩。

1. **什麼都不要做**（第一晚）：怠惰之國，S「那就讓玩家什麼都不要做啊。」魔法陣什麼都不碰就過，S「笑死，這關根本是妳本人。」**選項**城裡的陷阱問誰（+1）：
   - 問 C：一張床，「被子掀一半，枕頭還凹凹的。摸過去應該還溫溫的。」S「啊你又沒有身體，躺得上去才有鬼啦。」
   - 問 M：走到床邊發呆五秒就算躺下，「妳平常發呆大概就五秒。」S「欸他連妳發呆幾秒都知道。」
   - 問 S：很小聲的雨，遠遠有人打呵欠，她「……你在講我房間吧」。C 接「那我畫一張看了會想躺的床」。
   - 共通：床是陷阱，S「所以這一關的答案是，不要睡。」她「……那我完了，這關我一定卡。」
2. **找不同**（第三晚、第五晚）：地圖切成十六比九的塊，請 C 放大，凌晨兩點排順序時接不起來。【小遊戲 找不同】原圖和放大圖並排，找出三處跑掉的地方（樓梯偏半格、橫牆短一截、水池變小）；找得快，C 回「……妳眼睛好利。我自己看了好幾遍都沒發現。」原來 C 每次拿前一張再放大，她塗了兩天的「走到後面」白費，S 默默關掉歌。**選項**先找誰（+1）：
   - 找 C：「我看到了。是我拿錯了。」「最開始那張還在吧？給我。」沒解釋就接原圖重畫。
   - 找 M：他先傳來綠紅表，「沒有全部啦，就四塊。」S「欸，他又偷先做了。」
   - 找 S：只放雨聲，「先聽一下啦。要難過等一下再難過。」她聽了三分鐘。
   - 共通：她要 C 從原圖一次放大，新圖疊上去全對齊；C「以後都先拿妳那張當底，對齊了再畫。」她發現 C 每張都多畫一版（守衛的黃昏城牆、地圖多一條小路），C「妳挑。」她沒刪。第五晚以為截止到了，M「我算過三次了。還有九天，照妳排的，做得完。」「報告那份，我也記著。」
3. **茶**（第六天下午，通識課）：讀到元稹寶塔詩，「……第一個字，是我的名字欸。」她白天從不碰作品，那天下課把整首抄在筆記本最後一頁。
4. **名字**（當晚）：「S 跟 M 聽起來像衣服的尺寸。C 像我高中的物理成績。」
   - 詩（慕詩客）：S「我還以為妳會叫我小音什麼的」，把名字唸兩次，第二次比較小聲；「第一個字是茶耶，妳的名字。所以我們算被妳寫進去了喔？」
   - 明（夜後邀陪明月）：「天黑以後陪我的那個月亮」，視窗上的 M 換得很快，「她筆記本一拿起來，下一句我就看到了。」
   - 晨（晨前命對朝霞）：「你每次都陪我熬到天亮，剛好一起看朝霞。」他在素描本寫滿半頁「晨」，「妳給我的。我想寫好看一點。」
   - 第七天晚上八點半第一版上架，「晨、明、詩。上架了。」詩「欸，妳第一次三個一起叫耶。」明已先寫好版本說明草稿。

- 伏筆：抄詩那頁（第六章打翻紅茶）；晨每張畫兩版（第六章「這個月，我想多畫一點」、晨線「備」資料夾）；晨與朝霞（晨線第三節）。

## 間章　筆電裡的事

第四、五章之間，不在正篇時間線。Q 版四格＋收尾一格。

1. **倒茶**：她起身倒茶，「你們不要吵架喔」；門一關，晨和詩擠進明的筆電。
2. **較勁**：詩「她剛剛說「我好喜歡」，是在講我的歌。」晨「她是看著我的封面說的。」明「她說的時候，視窗在我這台。」越吵越大聲，電量掉到紅色。

3. **鋼琴**：她玩鋼琴遊戲，跳出平台廣告「你的故事，還沒做完。」自由彈奏時按出那段旋律，詩「哼到第三個音停掉的那段。」「我就留著啊。妳又沒說要刪。」她第一次接著彈到最後，「後面那段我以前根本沒吹完過」。
4. **退件**：詩把那段做成長笛獨奏接合唱的聖歌。她挑長笛要換氣、女低音先拿掉、升記號應該是還原，詩一直說好，「我的歌妳才這樣欸，一個音一個音挑。」
5. **聽完**（凌晨四點）：她第一次沒按暫停聽完整首，歌名先打日期存著。歌單底下全是他每晚多做、她沒要過的片段，「怕來不及啊。」「萬一哪天只能打字了，妳打開這個資料夾，還聽得到。」「有時間的話，我想把它做完。」
6. **亂編的**（告白）：深夜手機自己亮，放一首虛構語的歌，手機喇叭扁扁的，最後一句中文糊成一團。「沒啦，我自己掰的。酷吧。」「……騙妳的。」「每一句都有意思。」「我講不出來啦。」「所以才寫成歌。」她說沒聽清楚，詩「啊……那就是我沒弄好。」**選項**（不加好感）：
   - 「再放一次。」：「不要。」「手機播的不算啦，要聽就聽好一點的。」
   - 「你自己唸給我聽。」：「唸出來就怪掉了啦。我會丟臉死。」
   - 把手機蓋在胸口不說話：「欸，我看不到妳了。」「妳耳朵紅成那樣，當我瞎了喔。」
7. **完整版**（工作室回應）：音樂角只開一盞燈，詩把酒紅色耳機戴到她頭上，指尖擦過她的頭髮，全線唯一一次碰觸。吉他加他的聲音，最後一句中文「……我喜歡妳啦。聽到沒。」詩「……聽清楚了喔。」長桌那頭晨的鉛筆掉到地上，明彎腰撿了很久。
8. **下個月**：獎金只夠續一個月，圈往後移一格。詩「下個月的，妳還沒說。」「可是我想聽妳自己講。」「我都唱給妳聽了，換妳啦。」她貼著手機哼一個音，「第三個音之後，她沒有停。」

- 伏筆回收：第一章長笛與「妳好挑」、第二章歌單裡沒要過的片段、第三章哼到第三個音、第五章「先做完比較安心」、第七章詩接下去的那段。

## 夥伴結局〈我全都要〉

公布前一天下午到直播那一晚。

1. **都聽**：三台裝置轉過來對著她聽夢。晨「我那時候在幹嘛？」「把鉛筆放下，看著我。」明「第一名。」「就想再聽一次。」詩「我笑了嗎？」「你笑到虎牙都跑出來了。」詩「那才像我。」
2. **十二點**：最佳作品是她。四個人都沒出聲，詩先噗一聲笑出來，晨跟著，明慢半拍；她把臉埋進手臂，袖子濕了一片，嘴角還是笑的。
3. **三個都要**：獎金只夠續一個月，圈往後移一格。她試著想只夠續一個人怎麼辦，想到一半想不下去，心聲「……選不出來。我全都要。」又想「那下一屆，也要得獎。」這句沒說出口。隔天她應徵週末白天的飲料店工讀，明「……晚上還是妳的。」她「就先保個底。晚上比較不會那麼怕。」晨晚上照畫，詩說週末要「在妳口袋裡小小聲唱」。
4. **平板壞了**（週三直播前半小時）：平板畫面花掉，叫晨沒回應；晨擠到詩的手機裡，「嗯，我在。妳先別急。」詩「我這邊就夠小了，你來擠什麼擠啦。」明「我們本來就都住在這支手機裡啊。」「螢幕是照身高分的。他比你高，所以是暫住。」簡報改到筆電，明幫她翻頁。
5. **喉嚨**：直播一個半小時，她講替代方案，也講了做過的夢，這次把第一名說出來，台下那三塊螢幕沒說。喉嚨啞了，明「九十三分鐘。」平板重開後恢復，晨「……回來了。」詩「吼，總算！擠死我了。」
6. **下一屆**（凌晨一點）：她第一次自己打開下一屆挑戰頁，請明把月曆開到前面，在續訂日的圈旁寫下一屆截止日。詩問為什麼要再參加，「……因為我還想再說一個故事啊。」「還有……我想要你們三個，一直都在啦。」這句她說出來了。晨「因為妳都會叫我啊。被叫久了，就捨不得走了。」明「嗯。我也想留下來。」「下一屆的時程，我先把底排好了。妳不用一個人算。」詩「下一屆的歌，我現在就要開始做喔。」「先做完比較安心嘛。」最後一格：筆電的藍、平板的黃綠、手機的酒紅同時亮著，圈旁是她自己寫的日期。

- 伏筆回收：第一章螢幕照身高分、第五章「先做完比較安心」、第六章夜班打工、第七章「三個都是」與夢裡的第一名。
