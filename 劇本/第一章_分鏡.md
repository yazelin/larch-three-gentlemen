# 第一章分鏡表（導演視角）

> 2026-11-06 起，每張 CG 先在這裡定好鏡頭，才寫提示詞。機位圖（`canon/plans/`）只負責空間不跑掉；這份負責觀眾的眼睛被帶到哪裡、感覺到什麼。

## 規矩

- 每一格都要畫到精緻（yazelin 2026-11-06）：淡水彩是畫法，不是隨便的理由。光的方向與顏色、材質（木紋、玻璃、布料、金屬）、背景物件、髮絲與眼睛的細節都要清楚，驗收時跟電影劇照比，不跟插圖草稿比。
- 每一格寫齊六欄：**目的**（這一格要觀眾感覺到什麼）、**景別**、**角度與鏡頭位置**、**焦點與景深**、**光**、**視線**。缺一欄不准送產圖。
- 一節戲的鏡頭要有順序：先交代空間（遠景），再推近（中景、近景），情緒最高的那一句才給特寫或反打。不連續用兩個一樣景別的鏡頭。
- 手不靠切身體藏，靠取景藏：要藏手就拍胸口以上的坐姿或背影，不准出現「一顆頭擱在畫面邊緣」。
- 三位先生在畫面裡要有視線落點（看她、看彼此、看自己的東西），不准三個人各自看天花板。
- 越肩鏡頭只能從現實裡站得到的位置拍：螢幕是朝著她的，所以越肩要越「她的」肩看螢幕裡的人；從螢幕那一側看她時，前景是裝置的邊框與光，不是他的背影。
- Larch 沒有推軌與搖鏡，運鏡用「切」做：同一張大圖裁成由遠到近的幾張，連著換背景就是推近（cut-in）；轉場用 `fade`／`blurCut`／`fadeBlack`／`irisIn`，只在情緒轉折用 `flash`。
- **CG 與字數的比例要排（yazelin 2026-11-06）。** 每一段先定模式：
  - **情緒段**：多張 CG 連著切，字少。一張 CG 配一到兩句，能用畫面講的就把台詞砍掉。
  - **對話段**：固定一個主鏡頭，字可以多，但每一到三句換一張**表情差分**（同構圖，只換眉眼嘴、頭的角度、誰看誰）。不准一張 CG 撐整段。
  - 差分一律從該格的**主鏡頭定稿**一次改出來，不拿上一張差分再改（修圖不疊改）。
  - 任何一張圖連續撐超過四句就要回頭檢查。
- **這是大人的故事，是視覺小說，不是兒童繪本（yazelin 2026-11-06）。**
  - 表演要克制：情緒放在眼神、呼吸、停頓、視線移開、嘴角一邊動，不用鼓臉、跳腳、嘟嘴、比手勢、汗滴、漫畫符號。
  - 人物比例寫實（成人頭身），不 Q 版、不大頭。
  - 畫面像電影劇照：明暗對比、留白、前景遮擋、調色有主色調（深夜偏藍與琥珀，工作室偏暖白），淡水彩只是筆觸。
  - 安靜的鏡頭可以完全不說話。
- 首尾呼應：第一章第一格與最後一格是同一個鏡位，前者螢幕全亮、她醒著，後者螢幕依序暗掉、她睡著。

## 演出層（整章的手法）

驗收標準：讀完會被打動（yazelin 2026-11-06）。底下每一條都要落到格號。

1. **視角越線**：一到五節，鏡頭永遠在她這一側的桌面（觀眾跟她一起看螢幕）。第六節 01-7 起，鏡頭第一次越過那條線，站到螢幕那一側看她。觀眾換到他們的眼睛，「她不知道，他們知道」用鏡頭說出來，不用台詞說。
2. **框中框＝自由與限制**：書桌上的三位先生永遠被螢幕邊框框住（限制）；工作室裡沒有任何框，四個人在同一個空間（自由）。第六節最後三個框依序變黑。題目的主題放在構圖裡，不靠台詞講。
3. **冰紅茶是時鐘**：01-1 冰塊融掉一半；05 凌晨三點冰塊沒了，杯壁的水珠滑下來；06 杯子空了，杯墊上一圈水痕。不寫時間也看得出夜很深。
4. **三種光**：黃綠（晨）、藍（明）、酒紅（詩）。01-3 第一次亮起，01-4 同時打在她臉上，01-7 疊在她頭髮上；06-3a 到 06-3c 一種一種從她頭髮上離開，最後只剩檯燈的琥珀色，跟 01-0 開場一樣。
5. **鎖**：01-2c 她敲三下鎖就開了，很輕鬆；06-1 明的月曆上那個圈是這一章最後一道鎖，誰都敲不開。06-1 構圖仿 01-2b（同樣是螢幕特寫、中央一個記號）。
6. **閃回對比**：03A-5「兩年前…五張 CG，我畫了兩個月」插一格閃回 03-F：同一張書桌，更年輕的她一個人在畫，低飽和、邊緣暈開；06C 晨說「五張，畫了兩個月」時再閃一次同一格，這次畫面一角多了平板的黃綠光。
7. **伏筆回收**：06M「她剛剛算過帳」時，閃回 02A 的計算機俯拍，調成冷藍。
8. **聲音省著用**：第一節沒有配樂，只有房間的底噪（冷氣、遠處的車聲），手機通知只用一聲很輕的震動聲（自製，不用鈴聲）。全章第一次響起完整的音樂是 05-1 詩開唱，所以那一刻最大聲。第六節同一首歌轉成耳機漏出來的小聲版本（悶、遠），06-3a 起淡出，06-4 完全無聲。
9. **節奏**：情緒段用短句加快切；06-3a 到 06-4 不說話，開 `autoAdvance`，每格停 2.5 秒，`fade` 600ms。第六節打字速度調慢。
10. **留白**：06-4 她只占畫面右下角很小一塊，其餘是暗下來的房間；跟 01-0 同一個鏡位，差別只有三台裝置都黑了。
11. **想像畫面**：05-4 用一整格畫她腦中的教堂與跪下的人，取代那句說明心聲。這一章唯一一格不是現實的畫面。

12. **讓讀者就是茶語（yazelin 2026-11-06）**：每位先生的心動點都給一格**主觀鏡頭**，鏡頭就是她的眼睛，他直視鏡頭、只看著「妳」。主觀鏡頭裡她不入鏡（最多露一點她的髮梢或手機邊緣），讀者才坐得進她的位子。其他鏡頭維持「不看鏡頭」。
13. **三個都喜歡、很難只選一個（yazelin 2026-11-06）**：
    - 第一章三人的份量要一樣：心動點、主觀鏡頭、獨白句數，逐人數過，差距不超過一格、兩句。晨是「他把妳說的每句話當真」，明是「他替妳把路先走一遍」，詩是「他聽得見妳還沒說出口的東西」，三種喜歡不互相取代。
    - 選項前 04-P：三格主觀鏡頭快切（04-PC 晨抬眼看妳、04-PM 明等妳開口、04-PS 詩摘下一邊耳機），每格只停一句，然後選項才出現。
    - 選完之後各補一格 04-after：沒被選的兩人，一個視線移回自己的素描本或螢幕，一個笑容停了一拍才又笑。讀者要感覺到「選了一個，就讓另外兩個等」。
    - 第六節三人各有一句只屬於自己、跟她有關的話（晨「這次換我畫」、明「先別告訴她」、詩「讓她得獎就好了」），句尾各給一格他看著她的近景，份量一樣。

14. **真的運鏡（2026-11-06 實測可行）**：Larch 的影片層 `stage.videos` 可以逐句放短片。CG 先產高解析大圖，再用 ffmpeg 做成 3～8 秒的推近（push-in）、拉遠（pull-out）、橫搖（pan）、上搖（tilt）、焦點轉移（同構圖兩張交叉溶接）、光影變化（檯燈閃、螢幕光呼吸）。每段鏡頭照情緒選：
    - 發現、心動 → 慢推近；孤單、收尾 → 慢拉遠；情緒轉向 → 焦點轉移；緊張 → 快切加輕微手持晃動；回憶 → 溶接加暈邊。
    - 淡入淡出、溶接、漸變（色調慢慢變暖或變冷）都做進影片裡，不只靠卡片轉場。
    - 目標是讓人分不清是視覺小說還是電影；但每句台詞讀完前，鏡頭要停下來，不搶字。
15. **心跳感（dokidoki）與雀躍感（wakuwaku）一定要有（yazelin 2026-11-06）**：
    - dokidoki：主觀鏡頭的慢推近，他的眼睛停在畫面三分線上；那一句前 BGM 抽掉，只剩 `heartbeat` 很小聲；台詞逐字慢打。每人第一章至少一次。
    - wakuwaku：01-2 通知到 01-2c 鎖彈開、03-0 三道光飛出去、04-0b 掉進工作室，用快切、`flash`、亮色、節奏感強的音效。
    - 讀者驗收時要逐節回報「哪一格心跳了、哪一格雀躍了」，沒有的節要補。

## 採用 deepseek 導演審查的部分（2026-11-06）

- 刪掉改成純畫面：「來了來了來了」（01-1 指尖懸著、呼吸停一拍、冰塊輕響）、「好，報名了」（01-2c 嘴角動一下）、「人形……介面？」（01-3 三色光映在瞳孔）、「好像在聽教授講報告要先寫大綱」（04M-3 眼神從困惑變安心）、「他講的那個聲音，我好像真的聽得到」（04S-5 閉眼、窗光在睫毛上）、「睡不著」（05-0）。
- 身高梗縮短：詩只挑眉、明不看他，笑點靠沉默。
- 04C-1 草圖先畫一道門框，第二張才補完；04S-1 詩敲桌打拍、哼錯一音再重來。
- 06A-4「讓她得獎就好了」：詩笑一下又收，晨與明不笑。
- 補明：04-PM 主觀鏡頭明直視「先試一輪，撞到再換方法」；04-after 明調低螢幕亮度、視線停在她空出來的椅子。
- 打字速度演戲：「蛤？」慢打停 0.8 秒；「先別告訴她」逐字慢打，像怕吵醒她。
- 色彩抽離（第六章她檢查 CG 時畫面去色，只剩三台裝置有顏色）、時間切片（4:59／5:00 同構圖兩格）留給後面章節。

## 記號

`主鏡頭 03A`：對話段的固定鏡頭。`03A-2`：它的第二張表情差分。`01-0`：情緒段的單格。每一格的六欄寫在「格」底下；差分只寫跟主鏡頭不一樣的地方。
